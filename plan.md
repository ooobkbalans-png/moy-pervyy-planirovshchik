## Общие правила работы

- После каждого шага получается запускаемый результат с работающими функциями этого шага. Проверки выполняются до объявления шага завершенным; обнаруженные блокирующие дефекты исправляются сразу.
- Разработчик самостоятельно проверяет расчеты, права, формы, кнопки, переходы, сохранение и ошибки. Проверка логики дополняется действиями в браузере: одного просмотра кода недостаточно.
- Для календарных сценариев использовать тестовую дату и эталонное демо из ТЗ. Не менять часы компьютера. Для разрушительных проверок использовать тестовую копию данных.
- После изменений проверять сохранение при перезагрузке и повторять затронутые проверки предыдущего шага. Полный повтор всех сценариев выполняется перед итоговой поставкой.
- Результаты записывать в Markdown-протокол по шаблону раздела 20 ТЗ: среда, набор данных, сценарий, ожидание, факт, PASS/FAIL/NOT RUN, дефекты. Непроведенную проверку не называть успешной. Если автоматическая проверка недоступна, фиксировать ограничение и искать доступный способ проверки, а не автоматически перекладывать ее на заказчика.
- Заказчику оставлять оценку внешнего вида, понятности и удобства рабочего процесса. Кнопки, сроки, формулы и сохранение заказчик не обязан перепроверять вместо разработчика. Руководитель утверждает итог по протоколу и демонстрации.
- Реализовать Must из ТЗ. Should сохраняют желательный приоритет, их отсутствие отмечается отдельно и согласуется при приемке. Could не добавлять отдельными работами. Будущие серверные функции не реализовывать.
- Поставка приложения — только `index.html`, `styles.css`, `app.js`. Протокол проверок — документ приемки, не дополнительный файл приложения. Новые функции, сервисы, бюджеты и календарные сроки работ этот план не вводит.

#### Нюансы и принятые решения

- Без готовых файлов NT Somic и отдельного логотипа использованы разрешенные ТЗ текст «Финалогика» и Segoe UI/Arial. Цвета взяты из ТЗ; шрифт внутри таблицы не меньше 12 px.
- Демо формируется один раз: 20 активных пользователей, 380 клиентов (375 активных, 5 снятых), 2288 назначений. При начальной дате 13.10.2026 месячный план содержит 2100 задач, квартальный — 3800. Повторы и имена определены фикстурой, не случайной генерацией.
